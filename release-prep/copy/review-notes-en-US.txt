TabForge includes a keyboard extension and a companion playground with setup help, source/privacy links and on-device voice input. All features work without a TabForge account or purchase. No demo credentials are required.

Version 1.1.0 adds long-press alternates, a configurable toolbar and haptic strength. Key clicks use UIInputViewAudioFeedback, which needs no Full Access and follows the Keyboard Clicks setting. Optional autocorrect now ranks replacements on the device by tap position, word frequency and nearby words. New option Learn my tap positions defaults off; it stores only per-key average tap offsets locally and is erased when turned off. The 1.0.1 Tip Jar is unchanged: optional consumables that unlock nothing.

Keyboard setup:
1. Open TabForge. The Playground works immediately with its in-app keyboard.
2. To test the extension, open iOS Settings > General > Keyboard > Keyboards > Add New Keyboard and choose TabForge.
3. In a compatible app, hold the globe key and select TabForge. The globe also switches to another keyboard.
4. Full Access and App Groups are not requested. Configure the installed keyboard and manage snippets from its gear menu. It saves them in its own local preferences; the companion does not configure or synchronize them. The extension does not launch the companion app.
5. Companion keyboard/layout guides are labelled previews. Their settings and snippets stay in memory. The playground draft is saved separately on the device.

Input profiles:
- Code editor supports eligible pairing, indentation and local edits. Destructive line actions decline if host context is insufficient to verify them.
- Terminal · ANSI inserts tabs, ASCII Control characters and configured ANSI navigation sequences. It needs a client that forwards them; it cannot synthesize hardware-key events.
- Remote desktop inserts literal text with smart transformations disabled. The client controls forwarding. Unsupported combinations are declined.

Optional input:
- Autocorrect prose (English) defaults off; enable it in the gear menu. UITextChecker finds misspellings; replacements come from bundled words and nearby text. It respects field traits and host opt-outs, skips code-like text and stays inactive in Terminal, Remote desktop and the playground. Space applies a correction; immediate Delete restores the spelling.
- Swipe typing (beta) is experimental and defaults off. It uses bundled English/code words and nearby document words offline, with alternatives in the gear menu. Document/layout changes discard traces and alternatives. It is not Apple QuickPath.
- Voice to code is in the Playground toolbar. Tap the microphone, then Start recording. This user action requests microphone and Speech permission. Recognition requires on-device English support without a cloud fallback. Review the transcript before Insert. Dismissal, cancellation, backgrounding or audio interruption stops recording. Unavailable recognition does not block typing.

Privacy:
The extension does not save host text, tap points, swipe traces, speech audio or supplementary lexicon entries. Optional tap learning saves only per-key average offsets locally. The companion saves its playground draft separately; an inserted transcript becomes part of that draft. Existing keyboard-local records are retained; older shared/companion records are not imported or erased. StoreKit stays in the companion. It processes transaction results locally without a purchase backend, transaction upload, logs, receipts or app-maintained purchase history. Apple handles payment and its own transaction records. TabForge has no accounts, analytics, advertising or remote input service. Source, privacy, security and offline license notices are linked in the app.

Compatibility:
iOS/iPadOS 27.0+; Duo geometry requires 27.1. iOS uses the system keyboard in secure and phone fields. Hosts may reject extensions or limit context. The playground edits text; it does not compile or run code.
