TabForge is an open-source keyboard for writing code, scripts and commands on iPhone and iPad. Brackets, Tab and editing controls stay close at hand.

Keep the punctuation you use close to the letters. Indent a line, move the cursor, insert a saved snippet or change an input profile from the keyboard's gear menu.

Programming keys
- Type braces, square brackets, angle brackets, parentheses and full ASCII punctuation.
- Choose Tab, two spaces or four spaces, with indent, outdent and automatic newline indentation.
- Use arrows, Escape and Control, Option and Command keys, with behavior matched to the selected input profile and host app.
- Save snippets for commands, operators and repeated text.
- Get language suggestions for Swift, Python, JavaScript, TypeScript, Shell and JSON.

Layouts for your screen
Phone layouts keep familiar letter keys with coding controls close by. Compact landscape layouts make room for the app above the keyboard. Roomier iPad and supported Duo layouts expose more controls. Choose your key size and keyboard height, follow iOS light and dark appearance, or select a code palette.

Editing and input profiles
Use Code editor for pairing and indentation, Terminal · ANSI for supported control text, or Remote desktop for literal input. Terminal and remote behavior depends on the client: a keyboard extension inserts text and cannot send arbitrary hardware-key events. Line edits need enough context from the host app to verify the change.

Optional English prose autocorrect uses Apple's on-device spelling service in eligible text fields. It is off by default, skips code-like input and stays inactive in Terminal, Remote desktop and the code playground. Space applies a correction; immediate Delete restores your spelling.

The companion playground includes syntax highlighting, line numbers, undo and a share action. Its keyboard and layout previews use temporary settings, separate from the installed keyboard. Its voice-to-code tool lets you dictate, review spoken punctuation and insert the result. Voice input requires microphone and Speech permission plus available on-device English recognition. It runs in the companion app; system Dictation availability is controlled by iOS. Optional swipe input is experimental and limited to a bundled coding vocabulary. The playground edits text; it does not run code.

Open source and privacy
TabForge is MIT licensed, with source and privacy details linked in the companion app. The keyboard does not log or transmit keystrokes. There are no ads, analytics or accounts. Keyboard preferences and custom snippets are saved in the keyboard's own container. The companion playground saves its draft separately. Apps you type into, Apple system services, device backups and destinations you choose when sharing have their own data practices.

Full Access is not requested. Configure the keyboard and manage custom snippets from its gear menu. These settings and snippets are not shared with the companion app.

Requires iOS or iPadOS 27.0 or later. Duo-specific layouts require 27.1. iOS uses its system keyboard in secure and phone fields, and some apps decline third-party keyboards.
