# Product page header

The header is brand artwork. The listing screenshots use real captured UI instead.

Generate a wide, top-down composition inspired by the existing TabForge app icon. Place a complete three-by-three cluster of nine keys near the center, occupying about 42% of the width and 72% of the height. Keep every key and label inside the composition. Use these rows: `[ ] /`, `< {} >`, and `⇥ ⌘ ↵`. The four outside corners of the cluster should follow the broad curvature of the app icon, while the inner corners remain tighter. Keep the key surfaces nearly flat, with very little bevel and a restrained soft shadow.

Use warm chalk `#F2F0E9`, graphite `#20261F`, and a pale lime `#D4E9A5` center key. Leave generous quiet space around the cluster so the artwork survives device cropping. Use a 21:9 composition. No headline, slogan, logo text, phone frame, ribbon, glow, particles, or blue/teal treatment.

The generated master was resized to Apple's 3840 × 1646 product-page header specification and checked for an opaque RGB output. The exact image, upload receipt, and placement receipt are retained in the ignored release artifacts. Assignment to a draft placement does not submit the artwork for review.
